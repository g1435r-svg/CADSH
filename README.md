# ניהול מעשרות וחומש

> אפליקציה לניהול הכנסות, תרומות, מעשרות וחומש — עם ייבוא מאקסל, דוחות וגרפים.

## ✨ פיצ'רים

| פיצ'ר | תיאור |
|---|---|
| 📊 לוח בקרה | תמצית הכנסות, מעשר (10%), חומש (20%) עם progress bars |
| 📋 רשומות | ניהול הכנסות ותרומות, סינון, מיון, חיפוש |
| 📈 דוחות | גרפים חודשיים/שנתיים, סטטיסטיקות, עוגת קטגוריות |
| ⬆️ ייבוא אקסל | תמיכה בקבצי בנק ואשראי, מיפוי טורים, תבניות שמורות |
| 💾 גיבוי | ייצוא/ייבוא JSON, CSV, XLSX |
| 🌙 מצב לילה | מעבר בין תאורה בהירה לכהה |
| ↩ בטל/שחזר | תמיכה ב-Undo/Redo עד 100 פעולות |
| 🏷️ קטגוריות | סיווג תרומות לפי קטגוריה (מוסד, עני, ישיבה וכו') |
| 📅 תאריך עברי | המרה אוטומטית לתאריך עברי |
| 🖨️ הדפסה | הדפסת רשימת הרשומות |

---

## 🚀 הרצה מקוד המקור

```bash
cd maaser-chomesh-upload
npm install
npm start
```

## 🔨 בנייה ל-EXE

```bash
cd maaser-chomesh-upload
npm install
npm run build:exe
```

הקובץ יישמר בתיקיית `dist/`.
