## 🚀 הרצה מקוד המקור

```bash
cd maaser-chomesh-upload
npm install
npm start
```

## 🔨 בנייה ל־EXE

ברוב המקרים אין צורך לבנות לבד — ה־EXE המעודכן זמין להורדה ישירה דרך עמוד ה־Releases.

אם בכל זאת רוצים לבנות מקומית:

```bash
cd maaser-chomesh-upload
npm install
npm run build:exe
```

הקובץ יישמר בתיקיית `dist/`.
