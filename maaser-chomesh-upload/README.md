# מערכת יבא יצא

מערכת חדשה לניהול נתוני כספים אישיים:

- יבא (הכנסות)
- יצא (הוצאות/תרומות)
- יתרה בזמן אמת
- גיבוי וייבוא JSON
- עריכה, מחיקה וחיפוש

## ⬇️ הורדה ישירה לווינדוס

**[לחץ כאן להורדת MaaserChomesh.exe](https://github.com/g1435r-svg/CADSH/releases/download/latest-build/MaaserChomesh.exe)**

## הרצה מקומית

```bash
npm install
npm run start
```

## בניית EXE

```bash
npm install
npm run build:exe
```

קובץ ה-EXE נוצר בתיקיית `dist` בשם `מערכת-יבא-יצא.exe`.
