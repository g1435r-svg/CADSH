# מערכת יבא יצא

מערכת חדשה לניהול נתוני כספים אישיים:

- יבא (הכנסות)
- יצא (הוצאות/תרומות)
- יתרה בזמן אמת
- גיבוי וייבוא JSON
- עריכה, מחיקה וחיפוש

## ⬇️ הורדה ישירה לווינדוס

**[לחץ כאן להורדת מערכת-יבא-יצא.exe](https://github.com/g1435r-svg/CADSH/releases/download/latest-build/%D7%9E%D7%A2%D7%A8%D7%9B%D7%AA-%D7%99%D7%91%D7%90-%D7%99%D7%A6%D7%90.exe)**

## הרצה מקומית

```bash
npm install
npm run start
```

## בניית EXE

```bash
npm install
npm run build:exe
```

קובץ ה-EXE נוצר בתיקיית `dist` בשם `מערכת-יבא-יצא.exe`.
