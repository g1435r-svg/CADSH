## יכולות עיקריות

- עריכה ומחיקה של רשומות
- הפרדה לתצוגות: כל הרשומות / הכנסות / תרומות
- חיפוש וסינון לפי תאריך וטקסט
- גיבוי וייבוא JSON של כל הנתונים המקומיים, כולל תבניות והגדרות
- ייצוא CSV
- מחיקת כל הנתונים המקומיים עם יצירת גיבוי מלא לפני המחיקה
- דוח חודשי ושנתי עם גרף
- ייבוא Excel מתקדם:
  - בחירת סוג ייבוא (הכנסות או תרומות)
  - תאריך אחיד לכל הרשומות (אופציונלי)
  - מיפוי טורים (תיאור, סכום, תאריך, הערות, מקבל)
  - בחירת שורות לייבוא (כל השורות או ידנית)
  - בחירת גליון (Sheet)
  - מצב שורת כותרת: כן/לא
  - נרמול סימן סכום: אוטומטי / כמו בקובץ / חיובי / היפוך
  - שמירת תבניות מיפוי לשימוש חוזר
  - קביעת תבנית ברירת מחדל
  - זיהוי אוטומטי של תבנית לפי שם קובץ
  - ייבוא מהיר בלחיצה אחת
  - ייצוא/ייבוא תבניות כקובץ JSON

## הרצה מקומית

1. התקן Node.js (גרסה 24+)
2. הרץ:

```bash
npm install
npm run start
```

או בקבצי הרצה מוכנים:

- `run-app.bat`
- `run-app.ps1`

## בניית EXE

```bash
npm install
npm run build:exe
```

או:

- `build-exe.bat`
- `build-exe.ps1`

קובץ ה-EXE יופיע בתיקיית `dist`.

## רעיונות לשדרוג נוסף

- חיווי צבעוני על עמידה ביעד מעשר/חומש לכל חודש
- סימון רשומות אוטומטי לפי מילים מהבנק (למשל "משכורת", "תרומה")
- תמיכה בקטגוריות תרומה (ישיבה, צדקה, משפחות)
- ניהול כמה חשבונות במקביל (אישי, משפחתי, עסק)
